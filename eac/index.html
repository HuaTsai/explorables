Engineering a Compiler 筆記

讀 Cooper 和 Torczon 的 Engineering a Compiler（第三版）時，把值得動手走一遍的演算法做成互動頁。每篇一個演算法，照書上的虛擬碼逐步執行，可以獨立閱讀。

這本書和它的 IR

這本書從掃描、剖析一路講到最佳化和程式碼產生，中段的例子都用它自己定義的線性中間表示 ILOC：一條指令一行，暫存器無限多，分支的目標都明寫。書上的演算法多半直接寫在 ILOC 上，所以這個系列的範例也用 ILOC，必要時會先說明用到的指令。

  • 從線性 IR 建 CFG

    一步步跑 FindLeaders 和 BuildGraph，看 label 怎麼變成 basic block 的開頭、block 的最後一條怎麼決定邊。可以自己改 ILOC 程式碼。

    Ch. 4

  • 區域值編號 LVN

    一步步跑 local value numbering，看值編號怎麼發、hash 表怎麼查、哪條運算被改寫成重用。可以切換基本版和擴展版（交換律、常數摺疊、恆等式），也會標出名字被覆寫後虛擬碼寫錯的那一刻。

    Ch. 8

  • 超區域值編號 SVN

    一步步跑 superlocal value numbering，看 extended basic block 怎麼定義、只有一個前驅的 block 怎麼接著前驅的 hash 表往下算、scoped hash table 怎麼進 block 開表、離開丟表，以及名字不是 SSA 時表為什麼會漏。可以自己改 block 和邊。

    Ch. 8

  • 樹高平衡

    一步步跑 tree-height balancing：第一階段找出每棵運算式樹的根，Balance、Flatten、Rebuild 把長鏈攤成葉子佇列再按等級重建成矮樹。原樹和重建樹並排畫出來，可以改程式碼和 live 集合。

    Ch. 8
